Privacy Policy

Last updated: 2026.

This page explains what information is collected, and what is not, when you use the FracSTAT desktop application and when you browse this documentation site. FracSTAT is developed as an open-source academic research tool, and this policy is written in that spirit: to be short, plain, and honest about the very limited amount of data involved.

1. The FracSTAT Desktop Application

FracSTAT itself is a locally-run, Python-based desktop application (see the Installation Guide). It does not phone home, does not include any analytics or telemetry, and does not transmit your fracture data, project files, imported SVG/Excel content, calibrated photographs, or exported reports to FracSTAT's authors, servers, or any third party. Everything you load, digitize, or calculate stays on your own machine, inside the project folder you choose, unless you yourself export or share a file.

Because FracSTAT is open source (see the License page), you or your institution's IT team are always free to inspect the source code on GitHub to independently verify this.

2. This Documentation Website

This documentation site is a static reference: it does not use analytics cookies, advertising trackers, or visitor fingerprinting. Standard, unavoidable web-server logs (such as IP address, browser type, and requested page) may be retained temporarily by whichever hosting provider serves these pages, purely for operational purposes like abuse prevention and uptime monitoring — the same baseline logging any web host performs automatically. FracSTAT's authors do not separately collect or analyze this information.

Images and some fonts on this site are served from third-party content delivery networks (see Section 4); loading a page may cause your browser to make requests to those providers in the ordinary course of rendering the page.

3. The Documentation Admin Panel

A separate, credential-protected admin panel is used internally by the documentation maintainers to edit and publish these pages. It authenticates against a private credential store and, once signed in, can commit changes directly to the site's GitHub repository on the maintainer's behalf. This panel is not intended for general visitors, collects no information about ordinary readers of the documentation, and is unrelated to your use of FracSTAT or this site.

4. Third-Party Services

This site relies on a small number of third-party services purely to host static assets:

  • Cloudinary — hosts the FracSTAT logo, screenshots, and other images embedded in these pages.
  • Google Fonts / cdnjs — may be used to serve web fonts or small JavaScript libraries referenced by individual pages.
  • YouTube / Google Drive — the Video Tutorials page embeds videos hosted on these platforms; playing an embedded video is subject to that platform's own privacy policy, not this one.
  • GitHub — the source code, issue tracker, and (for maintainers) content publishing pipeline live on GitHub, subject to GitHub's own privacy policy.

None of these services are configured by FracSTAT to build an advertising profile of visitors; they are used purely as content-delivery infrastructure.

5. Data Retention and Deletion

Because FracSTAT's authors do not operate a database of personal visitor information, there is generally nothing about an individual reader to retain or delete beyond the routine, short-lived server logs described in Section 2. If you have contacted the team directly by email (see the Contact page), that correspondence is retained only as long as reasonably needed to respond to and resolve your query.

6. Children's Privacy

FracSTAT and this documentation site are intended for structural geologists, geoscience students, and engineering professionals, and are not directed at children. No age-gating is implemented because no personal data is knowingly collected from any visitor in the first place.

7. Changes to This Policy

If this policy is ever updated — for example, if a future release of FracSTAT introduces an optional, explicitly opt-in feature such as crash reporting — the "Last updated" date at the top of this page will be revised and the change will be described here.

8. Contact

Questions about this policy can be sent to any of the addresses listed on the Contact page, or raised as an issue on the project's GitHub repository.
