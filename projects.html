Projects Page

The Projects page is the central list of recently used FracSTAT projects. It lets you find a project, load its metadata into the launcher, open a saved Analyzer workspace directly, import a portable project bundle, or remove an obsolete project.

On this page

  • Open the Projects page
  • Project list and controls
  • Project actions
  • Importing a project
  • Recent-project storage
  • Removing a project

1. Open the Projects Page

Select Projects in the launcher sidebar. The page reads the recent-project registry and displays the available records in a table. Use + New Project to return to the Home page with a cleared project form, or Import Project to open a portable .fracstat bundle.

2. Project List and Controls

Column or controlPurpose
Project NameThe name entered when the project was created.
Location / SiteThe descriptive field location or site name, followed by the project save directory.
Last OpenedThe stored date and time plus a relative value such as “2 days ago”.
Search projectsFilters records by project name, location, or save-directory path.
Sort byOrders records by Last opened, Name, or Date Created.
ActionsProvides Analyzer shortcuts, Load, and Remove controls for the row.

3. Project Actions

ActionResult
Open StaticLoads the selected project and opens its Static Analyzer workspace, restoring a saved Static session when present.
Open DynamicLoads the project and opens its Dynamic Analyzer workspace.
Open UncertaintyLoads the project and opens its Uncertainty Analyzer workspace.
LoadCopies the project name, location, and save directory into the launcher Home form without opening an Analyzer.
RemoveShows a confirmation and then removes the record and associated project files described in Section 6.
Tip: Use Load to inspect project details or choose a module from Home. Use an Open button when you already know which Analyzer you need.

4. Importing a Portable Project

  1. Select Import Project.
  2. Choose a FracSTAT .fracstat project file.
  3. Choose the folder into which the bundle should be unpacked.
  4. FracSTAT uses that destination as the imported project’s save directory and opens it through the standard project-loading workflow.

After import, the unpacked workspace session files behave like those of a locally created project. A .fracstat file can also be passed to FracSTAT by the operating system when the file association is available.

5. Recent-Project Storage

The recent-project registry is stored in .fracstat_projects.json in the current user’s home directory. The Maximum recent projects shown preference on the Settings page controls its limit, with a shipped default of eight.

Saved Analyzer sessions are project-specific sidecar files in the project’s chosen save directory. This separation lets each Analyzer reopen where it was left while keeping the launcher registry small.

6. Removing a Project

If saved sessions are detected, the confirmation explains that removal also permanently deletes the project’s Static, Dynamic, and Uncertainty session files, generated trace-map companion files, and project-specific folder under FracSTAT_plot_exports. If no session is detected, the dialog states that no session files were found.

Important: Removing a project is more than hiding it from the recent list. Preserve required exports or project bundles before continuing.
