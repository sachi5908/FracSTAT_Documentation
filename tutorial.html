FracSTAT: A Modern Software for Fracture Network Analysis
FracSTAT is an open-source, Python-based software designed for the analysis and characterization of fracture networks. It provides an integrated environment for fracture mapping, statistical analysis, structural visualization, stress-based analysis, and uncertainty assessment.
