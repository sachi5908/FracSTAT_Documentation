PDF User Manual

The complete FracSTAT documentation is also published as a single, print-ready PDF. It contains the same material as this website — installation, the three Analyzer modules, and the uncertainty workflow — collected into one continuous document, which is convenient for offline reading, for annotating during field or lab work, and for citing a fixed page number in a report or thesis.

If the viewer does not load

The embedded frame is a third-party resource, so a small number of environments will block it. The manual itself is always reachable through the two buttons above; the notes below cover the common causes.

  • A blank or grey frame usually means a privacy extension, a corporate proxy, or a strict browser setting is blocking third-party frames from drive.google.com. Use Open in new tab instead — it loads Drive directly rather than through a frame.
  • Offline reading: download the file once with Download PDF and open it in any local reader. The desktop application also ships the same manual alongside the executable, reachable from the launcher's Documentation page (see FracSTAT Home Page).
  • Printing: print from your own PDF reader after downloading rather than from the embedded frame — page breaks and figure scaling are set for A4 in the file itself.
Tip: the website is the version that gets corrected first. If a statement in the PDF disagrees with a page on this site, treat the website as authoritative and, if it matters for your analysis, report the discrepancy from the Contact page.
