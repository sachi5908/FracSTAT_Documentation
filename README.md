# FracSTAT

**FracSTAT** is a modern software application for **fracture network analysis**, designed to provide an efficient and user-friendly workflow for processing, analyzing, visualizing, and statistically evaluating fracture data.

It combines quantitative fracture analysis with modern visualization and statistical tools to support geological, structural geology, geomechanics, and related research applications.

## Features

* Fracture network and fracture dataset analysis
* Fracture orientation and length analysis
* Statistical characterization of fracture populations
* Fracture intensity and density analysis
* Spatial and geometric analysis
* Circular and directional statistics
* Uncertainty and sensitivity analysis
* Latin Hypercube Sampling (LHS)
* Monte Carlo-based analysis
* Interactive plots and visualization
* Data import and export
* Modular software architecture
* Research-oriented documentation and reproducible workflows

## Applications

FracSTAT can be used for:

* Structural geology and tectonic studies
* Fracture network characterization
* Geological and geotechnical research
* Reservoir and subsurface studies
* Geomechanical analysis
* Quantitative fracture analysis
* Research and academic applications

## Installation

Download the latest FracSTAT release and follow the installation instructions provided with the distribution.

If you are working with the source code, clone the repository:

```bash
git clone https://github.com/sachi5908/FracSTAT.git
cd FracSTAT
```

Install the required Python dependencies:

```bash
pip install -r requirements.txt
```

## Usage

After installation, launch FracSTAT and select the required analysis module.

The documentation provides detailed instructions for:

1. Importing fracture datasets
2. Preparing and validating input data
3. Performing fracture analysis
4. Running statistical analyses
5. Performing uncertainty analysis
6. Generating plots and results
7. Exporting analysis outputs
