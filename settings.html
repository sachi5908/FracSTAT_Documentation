Settings Page

The Settings page stores application-wide defaults for display scaling, plot text, stress inputs, Analyzer presentation, exports, and the recent-project list. These are starting values; project and tab controls can override them during an analysis.

On this page

  • Saving and resetting
  • Display and Workspace Text
  • Default Stress Parameters
  • Analyzer Defaults
  • Dynamic Analyzer
  • Static Analyzer
  • Export and recent projects

1. Saving and Resetting

Select Settings in the launcher sidebar, edit the required fields, and choose Save Settings. Preferences are written to .fracstat_settings.json in the current user’s home directory. Reset Defaults asks for confirmation, restores the shipped values, and saves them.

Display scale is different: Changing it is persisted immediately and FracSTAT offers to restart. A restart is required, and accepting it can discard unsaved project changes.
