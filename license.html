3. Third-Party Dependencies

FracSTAT is built on top of a number of open-source scientific Python libraries — including NumPy, pandas, Matplotlib, SciPy, the powerlaw package, and CustomTkinter, among others referenced throughout this documentation. Each of these carries its own license (most are BSD, MIT, or Apache-2.0). FracSTAT does not alter or override those licenses; consult each project's own repository for its exact terms. A consolidated list of dependencies and their versions is maintained in the requirements.txt file described in the Installation Guide.

4. Citing FracSTAT

If FracSTAT contributes to a publication, thesis, or report, the authors would appreciate a citation acknowledging the software and, where relevant, the specific module(s) used (Static, Dynamic, or Uncertainty Analyzer). See the Introduction page for the full author list and affiliations, and the Contact page for how to reach the team with a citation request or to confirm the preferred citation format for the current release.
